# ML Engineer Technical Assignment

**Objective:**
So, picture this: we stumbled across a repo on the internet claiming to implement a VAE [(Auto-Encoding Variational Bayes)](https://arxiv.org/abs/1312.6114). We thought, "Hey, this could be cool!"—but, wow, the code is a bit of a mess and doesn't even seem to run out of the box. Your mission, should you choose to accept it, is to rescue this project: understand the codebase, fix what's broken, clean up the chaos, and make it even better.

**Submission:**
Please submit your solution by sending a zip file of your project. Include adocument named `ANSWER.md` to summarize your key changes, design choices, and any challenges encountered and provide the instructions on how to run the project.

## Part 1: Codebase Setup, Refactoring, and Improvements

1.  **Project Setup & Execution:**
    *   Set up the project environment and ensure you can successfully run the training script (`src/run.py`) using the default MNIST dataset. The only rule is that you must use Python 3.12 or higher.
    *   Document the precise steps you took to set up your environment (python version, operating system, dependencies, etc...) and execute the training.

2.  **Code Refactoring:**
    *   Refactor the `Trainer` class in `src/trainer.py`. Apply good software engineering principles to improve its clarity, maintainability, and overall structure.
    *   Document the key changes you made and provide a rationale for them.

3. **Other Improvements**
    *   If you identify any other areas for improvement, feel free to implement them and briefly document what you changed and why.


## Part 2: Feature Implementation: Custom Dataset, Training, and Analysis

Given the following [images](https://drive.google.com/file/d/10ymTDxxZffBRHp1hZu2Lh52Q6JgMKiMG/view?usp=share_link) and the [bounding boxes annotations](https://drive.google.com/file/d/1zPFy_giFnQhcqicUgKCMdCZ6eFTWyxC9/view?usp=share_link) you will:

  1.  **Implement `PlateDataset`:**
      *   Create a new PyTorch custom dataset class, `PlateDataset` (e.g., in `src/plate_dataset.py`).
      *   Implement a dataset class that loads the images and annotations, and returns cropped plate images ready for the VAE.
  2.  **Training with `PlateDataset`:**
      *   Add an option to the training script (`src/run.py`) to allow training the existing VAE model using your `PlateDataset`.
      *   Train for a few epochs using the new dataset.
      *   Log and plot the training loss over epochs.
  3.  **Analysis & Results:**
      *   In your submission document `ANSWER.md`, briefly analyze the training process.
      *   Show a few examples of original cropped plates and their reconstructions generated by your trained VAE.
      *   Discuss any observations, challenges, or assumptions made.

## (Optional) Part 3: Extending Functionality: Conditional VAE (cVAE)

The current VAE implementation can be extended to a Conditional VAE (cVAE) that generates images based on specific conditions (e.g., class labels). Your task is to implement this functionality.

1.  **Implement Conditional VAE (cVAE):**
    *   Modify the existing VAE architecture (either `MLPVAE` or `CNNVAE` in `src/model.py`, or create a new cVAE class) to implement a Conditional VAE.
    *   The cVAE should be able to take a condition (e.g., a class label) as input during both encoding and decoding.
    *   Use the `PlateDataset` for this task, where the condition will be the plate class label provided in the dataset annotations.

2.  **Training the cVAE:**
    *   Update the training script (`src/run.py`) and `Trainer` class (`src/trainer.py`) to support training the cVAE with `PlateDataset`, providing both cropped plate images and their corresponding labels.
    *   Ensure the loss calculation and data handling are appropriate for the cVAE.

3.  **Conditional Generation:**
    *   Implement a functionality (e.g., a new method in `Trainer` or a separate script) to generate images of specific plate classes using the trained cVAE.
    *   Show a few examples of generated plates for different requested labels in your submission document.

4.  **Analysis & Discussion:**
    *   In your submission document, explain the architectural changes made for the cVAE.
    *   Discuss how the conditioning information is incorporated into the model.
    *   Briefly comment on the quality of the conditionally generated samples.
